Replicas are fixed at 1 and the strategy is Recreate. SQLite allows one writer.

CONFIG_SOURCE={{ .Values.env.configSource }}.
The ConfigMap {{ include "skylight-wifi-automation.configMapName" . }} is imported only when the database has no config.
After that, change settings in the UI. A later helm upgrade does not overwrite the database.
dry_run is {{ .Values.config.dry_run }}. While true, the process does not pause or resume UniFi objects.

Replace config.unifi_tls_ca before the first start. The placeholder certificate is rejected and the process exits.
files/unifi.local.example.crt is a generated unifi.local certificate for a smoke test, not a gateway certificate.

{{- if .Values.secrets.existingSecret }}

Secrets are read from {{ .Values.secrets.existingSecret }}.
APP_ENCRYPTION_KEY is required. ADMIN_SETUP_TOKEN, SKYLIGHT_EMAIL, SKYLIGHT_PASSWORD, and UNIFI_API_KEY are optional keys.
{{- else if include "skylight-wifi-automation.createsSecret" . }}

WARNING: this release created Secret {{ include "skylight-wifi-automation.secretName" . }} from Helm values.
Those values are also stored in the Helm release Secret. Prefer secrets.existingSecret.
{{- else }}

No Secret is configured. Create one with APP_ENCRYPTION_KEY (base64 of 32 random bytes) and set secrets.existingSecret.
Without that key, startup exits when SKYLIGHT_EMAIL, SKYLIGHT_PASSWORD, and UNIFI_API_KEY are also unset.
{{- end }}

First run, when ADMIN_SETUP_TOKEN is at least 32 characters and no admin exists:
  1. Open /setup and create an admin. The password must be at least 12 characters.
  2. Remove ADMIN_SETUP_TOKEN and roll the pod (bump secrets.rolloutToken if the Secret is external).
  3. Sign in. /setup returns 404 once an admin exists.

{{- end }}
